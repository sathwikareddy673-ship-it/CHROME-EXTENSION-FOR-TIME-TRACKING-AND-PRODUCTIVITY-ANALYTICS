**PRODUCTIVITY TRACKER CHROME EXTENSION WITH MONGODB DASHBOARD ANALYTICS

THE OBJECTIVE OF THIS PROJECT IS TO DESIGN AND DEVELOP A PRODUCTIVITY TRACKER CHROME EXTENSION THAT MONITORS USER BROWSING ACTIVITY, CATEGORIZES WEBSITES BASED ON PRODUCTIVITY, STORES USAGE DATA IN A MONGODB DATABASE, AND PRESENTS THE COLLECTED INFORMATION THROUGH AN INTERACTIVE ANALYTICS DASHBOARD. THE PROJECT COMBINES BROWSER EXTENSION DEVELOPMENT, BACKEND DEVELOPMENT, DATABASE MANAGEMENT, AND FRONTEND DASHBOARD VISUALIZATION INTO A SINGLE PRODUCTIVITY MONITORING SOLUTION.

THE CHROME EXTENSION CONTINUOUSLY TRACKS THE WEBSITES VISITED BY THE USER AND CALCULATES THE AMOUNT OF TIME SPENT ON EACH WEBSITE. THE EXTENSION UTILIZES CHROME APIS SUCH AS TABS AND STORAGE TO DETECT ACTIVE TAB CHANGES AND WEBSITE NAVIGATION EVENTS. WHENEVER A USER SWITCHES BETWEEN TABS OR OPENS A NEW WEBSITE, THE EXTENSION RECORDS THE WEBSITE DOMAIN AND CALCULATES THE DURATION SPENT ON THE PREVIOUS WEBSITE. THIS INFORMATION IS THEN PROCESSED AND PREPARED FOR STORAGE.

A BACKEND SERVER WAS DEVELOPED USING NODE.JS AND EXPRESS.JS TO MANAGE COMMUNICATION BETWEEN THE EXTENSION AND THE DATABASE. THE SERVER PROVIDES REST API ENDPOINTS THAT ALLOW THE EXTENSION TO SEND WEBSITE USAGE INFORMATION AND RETRIEVE STORED DATA FOR DASHBOARD ANALYTICS. THE BACKEND ACTS AS AN INTERMEDIARY LAYER BETWEEN THE EXTENSION AND MONGODB, ENSURING SECURE AND ORGANIZED DATA MANAGEMENT.

MONGODB WAS INTEGRATED AS THE DATABASE SOLUTION FOR STORING WEBSITE USAGE RECORDS. EACH RECORD CONTAINS DETAILS SUCH AS WEBSITE NAME, TIME SPENT ON THE WEBSITE, CATEGORY, AND TIMESTAMP. THE DATABASE PROVIDES PERSISTENT STORAGE, ENABLING THE APPLICATION TO RETAIN USER PRODUCTIVITY DATA EVEN AFTER THE BROWSER OR EXTENSION IS CLOSED. MONGODB COMPASS WAS USED TO MANAGE AND INSPECT THE STORED RECORDS DURING DEVELOPMENT AND TESTING.

A SEPARATE PRODUCTIVITY DASHBOARD WAS CREATED USING HTML, CSS, AND JAVASCRIPT. THE DASHBOARD RETRIEVES USAGE DATA FROM THE BACKEND SERVER THROUGH API REQUESTS AND DISPLAYS THE INFORMATION IN A STRUCTURED TABULAR FORMAT. THE DASHBOARD INCLUDES COLUMNS SUCH AS WEBSITE NAME, MINUTES SPENT, AND CATEGORY. WEBSITES ARE AUTOMATICALLY CATEGORIZED AS PRODUCTIVE OR UNPRODUCTIVE BASED ON PREDEFINED RULES. FOR EXAMPLE, EDUCATIONAL AND DEVELOPMENT WEBSITES SUCH AS GITHUB, LEETCODE, STACK OVERFLOW, AND GEEKSFORGEEKS ARE CLASSIFIED AS PRODUCTIVE WEBSITES.

TO PROVIDE MEANINGFUL INSIGHTS, ADDITIONAL ANALYTICS FEATURES WERE IMPLEMENTED. THE DASHBOARD CALCULATES TOTAL BROWSING TIME, PRODUCTIVE TIME, UNPRODUCTIVE TIME, AND PRODUCTIVITY SCORE. THE PRODUCTIVITY SCORE IS CALCULATED AS THE PERCENTAGE OF PRODUCTIVE BROWSING TIME RELATIVE TO THE TOTAL BROWSING DURATION. BASED ON THIS SCORE, THE SYSTEM GENERATES A WEEKLY PRODUCTIVITY REPORT WITH PERFORMANCE RATINGS SUCH AS EXCELLENT, GOOD, AVERAGE, OR NEEDS IMPROVEMENT.

THE DASHBOARD ALSO FILTERS UNWANTED ENTRIES SUCH AS LOCALHOST, CHATGPT, AND INTERNAL DEVELOPMENT WEBSITES TO ENSURE CLEANER AND MORE ACCURATE PRODUCTIVITY REPORTS. WEBSITE USAGE RECORDS FROM MONGODB ARE GROUPED AND SUMMARIZED TO AVOID DUPLICATE ENTRIES AND PROVIDE A CONSOLIDATED VIEW OF BROWSING ACTIVITY.

THE PROJECT DEMONSTRATES THE INTEGRATION OF MULTIPLE MODERN WEB TECHNOLOGIES INCLUDING CHROME EXTENSION APIS, JAVASCRIPT, NODE.JS, EXPRESS.JS, MONGODB, HTML, CSS, AND RESTFUL APIS. THROUGH THIS IMPLEMENTATION, USERS CAN EFFECTIVELY MONITOR THEIR BROWSING HABITS, ANALYZE PRODUCTIVITY PATTERNS, AND MAKE INFORMED DECISIONS TO IMPROVE TIME MANAGEMENT. THE SYSTEM PROVIDES A PRACTICAL EXAMPLE OF FULL-STACK WEB DEVELOPMENT AND REAL-TIME DATA TRACKING, WHILE SHOWCASING DATABASE INTEGRATION, API DEVELOPMENT, DATA PROCESSING, AND ANALYTICS DASHBOARD CREATION IN A SINGLE APPLICATION. THE SUCCESSFUL COMPLETION OF THIS PROJECT HIGHLIGHTS THE IMPORTANCE OF PRODUCTIVITY ANALYTICS AND DEMONSTRATES HOW WEB TECHNOLOGIES CAN BE USED TO BUILD USEFUL TOOLS FOR PERSONAL TIME MANAGEMENT AND PERFORMANCE IMPROVEMENT.**
